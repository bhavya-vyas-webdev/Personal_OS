# AlcarazOS
This is my very own OS that can be run in the web and is based on Carlos Alcaraz.

## Apps and Features
Apps of AlcarazOS are:
- Welcome
- Notes
- Grand Slams
  - Shows upcoming grand slams tournaments
- Weather
  - Might not work depending if your systems settings has blocked sharing location
- Stopwatch
<br>

Features of AlcarazOS are:
- Top Bar
  - Shows time, date, and button to open the welcome window
- Auto updating age, grade, and "as of ..." in the welcome window
